# Mi wishlist 💎

Página de deseos con temática de gemas. Los amigos pueden apartar un regalo
(sin crear cuenta) y la cumpleañera no ve cuáles están apartados.

- `index.html`: la página.
- `img/`: fotos de los productos. `art/`: recortes del collage.
- `apps-script/Code.gs`: el pequeño servidor en Google Apps Script que guarda qué regalos ya apartaron.

Modo sorpresa: abre la página con `#soy-la-cumpleanera` al final del link (una vez por celular).
Para quitarlo: `#ver-todo`.
